# Кино-главная imbored — план реализации

> **Исполнителю:** шаги помечены чекбоксами. Плавная прокрутка трогает весь сайт,
> поэтому фундамент идёт первым и проверяется отдельно от новой главной.

**Цель:** главная, где форма входа доступна с первого кадра, а рассказ о продукте
разворачивается шестью закреплёнными сценами по прокрутке.

**Архитектура:** ScrollSmoother на весь сайт (обёртка в корневом лейауте, четыре
`fixed`-оверлея переезжают в портал), лента обложек фиксированным слоем снаружи
обёртки, сцены — закреплённые секции с таймлайнами GSAP. Статический HTML
остаётся читаемым документом; при «уменьшить движение» вся хореография
выключается.

**Стек:** Next.js 16.3 (App Router, Turbopack), React 19.2, GSAP 3.15
(ScrollTrigger + ScrollSmoother), Tailwind 4, vitest 4.

**Спека:** `docs/superpowers/specs/2026-08-23-landing-cinema-design.md`

## Общие ограничения

- Маршрут `/` обязан остаться `○ Static` с ISR на час. Ни `cookies()`, ни
  `currentSteamId()`, ни пропа `searchParams` на странице.
- Форма подключения в проекте ровно одна, `id="steam-profile"` уникален.
- При `prefers-reduced-motion: reduce` не создаётся ни смузер, ни одно
  закрепление, и ни один элемент не остаётся спрятанным.
- Любой `position: fixed` обязан жить снаружи `#smooth-content` — либо в разметке
  лейаута, либо через `createPortal(node, document.body)`.
- Свет ленты считается от позиции прокрутки одной шкалой. Никаких скрубленных
  твинов на общий объект.
- Переключение состояния продукта в закреплённой сцене — на CSS-переходах.
- Тексты короче, но честные оговорки остаются мелким кеглем.
- Комментарии в коде — по-русски, объясняют ПРИЧИНУ, а не пересказывают строку.
